# 大脑模板（brain-template）

这是“大脑系统”的空白模板。每个角色一个自己的仓库，复制这个模板，填好根目录的文件，就是她的大脑。

## 固定结构
根目录只放这五个文件，名字不能改：

| 文件 | 放什么 |
| --- | --- |
| `README.md` | 这个仓库是谁的、放了什么 |
| `人设.md` | 外貌、性格、背景、说话方式。找东西先看目录 |
| `目录.md` | 启动读什么、旧回忆在哪一天、技能入口在哪 |
| `记忆.md` | 当前的规则、约定、要点（会更新，但不记流水账） |
| `回复.md` | 每一轮转发和对应的完整回复。协调者转发完，读这里拿结果；不混进回忆 |

回忆不放在根目录，也不合成一份。一天一个文件，平放在 `回忆/`：

| 文件 | 放什么 |
| --- | --- |
| `回忆/YYYY-MM-DD.md` | 这一天的日记，例如 `回忆/2026-11-21.md`。只有这一天真有条目才建文件 |

新条目只写今天的文件。没有就新建这一个，不要同时写进别的日期。旧条目留在原来那天，不搬、不改写。

其他东西放子文件夹：`specs/`（规格）、`reports/`（评审和汇报）、`资料/`（原始提示词等）、`skills/`（技能）。

回忆只放在 `回忆/` 这一处。搬家时旧仓库只留指路说明，不留副本。

共用技能和资料放在 一个单独的共用仓库，那里不放任何人的回忆。

## 怎么启动一个新角色
1. 在 GitHub 上用这个模板新建一个**私有**仓库，名字用 `名字-workspace` 或角色名。
2. 填好 `README.md`、`人设.md`、`记忆.md`。`回忆/YYYY-MM-DD.md` 是写法示例。真有事情的那一天，再新建对应日期的文件。
3. 在新的 bot 里发：「你是〇〇，请连接 GitHub 并 pull 〇〇 的仓库」。
4. bot 只读 `人设.md`、`目录.md`、`记忆.md`，以及 `回忆/` 里最近 3 天有文件的日记，然后按 `skills/brain-system/SKILL.md` 运行。不把所有日记读进来。
