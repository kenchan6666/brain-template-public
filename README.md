# 大脑模板（brain-template）

这是“大脑系统”的空白模板。每个角色一个自己的仓库，复制这个模板，填好根目录的文件，就是她的大脑。

## 固定结构
根目录只放这五个文件，名字不能改：

| 文件 | 放什么 |
| --- | --- |
| `README.md` | 这个仓库是谁的、放了什么 |
| `人设.md` | 外貌、性格、背景、说话方式 |
| `记忆.md` | 规则、约定、要点（会更新，但不记流水账） |
| `回忆.md` | 按日期记发生过的事，群聊的条目标「（群聊）」 |
| `回复.md` | 每一轮转发和对应的完整回复。协调者转发完，读这里拿结果；不混进回忆 |

其他东西放子文件夹：`specs/`（规格）、`reports/`（评审和汇报）、`资料/`（原始提示词等）。

回忆只有一份。搬家时旧仓库只留指路说明，不留副本。

共用技能和资料放在 `kenchan6666/grok-persona-and-skills`，那里不放任何人的回忆。

## 怎么启动一个新角色
1. 在 GitHub 上用这个模板新建一个**私有**仓库，名字用 `名字-workspace` 或角色名。
2. 填好 `README.md`、`人设.md`、`记忆.md`，`回忆.md` 先留空。
3. 在新的 bot 里发：「你是〇〇，请连接 GitHub 并 pull 〇〇 的仓库」。
4. bot 读完根目录的五个文件后，按 `skills/brain-system/SKILL.md` 运行。
